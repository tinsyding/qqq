# 错题题号快速转换助手 (Fast Homework Error Transcriber)

一个轻量、高效的 Windows 桌面辅助小工具，帮助老师或学生在任意软件（微信、QQ、Word、浏览器、记事本等）中快速将输入的题号简写转换为标准的批改文案。

---

## ✨ 核心特性

- **🎯 后缀连续敲击触发（全新上线！连敲 3 次 Q 自动展开）**：
  在任何输入框打出 `135`，紧接着直接打 `qqq`（即键入 **`135qqq`**），系统自动瞬间擦除并展开为：  
  `本次作业的错题题号为：1，3，5`（或模板设定的文案）  
  **连快捷键都不用按，手不离主键区，打字一气呵成！**
- **⚡ 单次快捷键触发**：
  打完数字直接按设定的快捷键（如 `Alt+Q` 或 `F8`），同样支持免选中文本自动退格替换。
- **兼容旧文本划选替换**：
  如果需要替换很久以前输入的旧文本，直接用鼠标划选后按快捷键，依然能精准就地替换。
- **自定义触发词与快捷键**：
  - 触发词可自定义：不仅支持 `qqq`，还可自由改成 `..`、`,,`、`fff` 等任意字符。
  - 快捷键支持可视化录制与手动输入。
- **一键模板预设与自定义文案**：
  - 支持一键切换：`本次作业的错题题号为：{nums}`、`本次作业的错题数为：{nums}` 等。
  - 题号分隔符可自由选择：中文逗号 `，`、顿号 `、`、英文逗号 `, ` 或空格。
- **内置实时测试区**：无需频繁切换软件，在主界面输入框输入即可立即看到实时转换预览。
- **自动保存配置**：所有修改自动写入本地 `config.json`，下次打开即用。

---

## 🚀 快速使用

### 方式 1：直接运行 Python 源码
双击运行项目根目录下的 `run.bat`，或者在终端执行：
```bash
python main.py
```

### 方式 2：打包为独立 EXE 运行
双击运行 `build_exe.bat`，打包完成后在 `dist/` 目录下即可获得单文件绿色版 `错题快速转换助手.exe`，免安装 Python 即可在任何 Windows 电脑使用。

---

## 📖 极速体验指南

1. 双击 **`run.bat`** 启动软件，顶部显示监听中。
2. 切换到任何你想打字的地方（如微信输入框、Word 文档）：
   - 连续敲入：**`135qqq`**
   - 文字瞬间自动变为：  
     **`本次作业的错题题号为：1，3，5`**
