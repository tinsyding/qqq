# 错题题号快速转换助手

Windows 桌面辅助工具，用于在爱问云快速将连续键入的数字简写展开为格式化的错题批注文案。

## 功能特点

- **后缀字符触发**：输入数字后直接键入指定后缀（默认 `qqq`，如 `135qqq`），程序会自动退格并替换为预设文案（如 `本次作业的错题题号为：1，3，5`）。
- **快捷键触发**：支持通过全局快捷键触发转换，支持光标前文本自动识别与鼠标划选文本替换。
- **灵活自定义**：
  - 自定义触发后缀（如 `qqq`、`..`、`,,` 等）。
  - 自定义文案模板（如 `本次作业的错题题号为：{nums}`）。
  - 自定义题号分隔符（中文逗号、顿号、英文逗号、空格等）。
- **实时测试**：软件界面内嵌测试输入框，便于即时调试转换规则。
- **配置持久化**：所有选项自动保存至本地 `config.json`，启动时自动加载。

## 使用示例

在爱问呀批语方框键入：

```text
135qqq
```

自动转换为：

```text
本次作业的错题题号为：1，3，5
```

## 运行与打包

### 1. 源码运行

安装依赖：

```bash
pip install -r requirements.txt
```

启动程序：

```bash
python main.py
```

也可以直接双击项目根目录下的 `run.bat` 运行。

### 2. 打包 EXE

双击运行 `build_exe.bat`，打包完成后在 `dist/` 目录下生成独立的可执行文件。
